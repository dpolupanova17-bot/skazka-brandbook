# Бренд-портал парка «Сказка»

Рабочая версия публичного онлайн-брендбука парка развлечений «Сказка».

Главная страница проекта — `index.html`. Проект статический и не требует сборки.

## Локальный просмотр

Откройте папку проекта через локальный HTTP-сервер и перейдите к `index.html`.

## Файлы проекта

Фирменные логотипы, палитры, шрифты, графика и доступные файлы для скачивания находятся в папках `assets`, `ЛОГОТИП`, `ПАЛИТРА`, `ПОЛИГРАФИЯ`, `ФИРМЕННАЯ ГРАФИКА`, `ФИРМЕННЫЕ ШРИФТЫ` и `ИКОНКИ`.

Исходник `ФИРМЕННАЯ ГРАФИКА/ГРАФИКА_и_персонажи.eps` временно не включён в репозиторий: его размер превышает лимит GitHub 100 МБ. Для публикации файла потребуется Git LFS или отдельное файловое хранилище.

## Раздел «Медиа»

В секции `#media` предусмотрены пять временных слотов. Чтобы добавить утверждённую фотографию, замените `.media-placeholder` внутри нужного элемента `[data-media-slot]` на `<img src="..." alt="..." loading="lazy">`.

Кнопка `[data-media-library-link]` намеренно не содержит `href`. После выбора способа размещения добавьте локальный или внешний URL, удалите класс `is-disabled`, атрибуты `aria-disabled` и `tabindex`; для внешнего хранилища также добавьте `target="_blank" rel="noopener"`.
